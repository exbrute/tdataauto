Как продаются подарки

            
Обычный подарок конвертируется в Stars сразу. Коллекционный NFT выставляется на маркетплейс Telegram — звёзды приходят, когда его покупают.

            
    
              
  • both — конвертация и витрина
    • 
              
  • convert — только мгновенные звёзды
    • 
              
  • resell — только цена NFT. 0 значит минимальную доступную цену
    •

Telegram API и бот

              
Сессия tdata открывается официальным API Telegram Desktop. Свои API ID и hash нужны, если вы также поднимаете бота приёма архивов.

Как пользоваться

            
    
              
  1. Закройте Telegram Desktop и заархивируйте папку tdata целиком.
    2. 
              
  2. На вкладке «Канал» вставьте ссылку на пост, например https://t.me/name/32.
    3. 
              
  3. На вкладке «Запуск» выберите ZIP или папку и нажмите кнопку продажи.
    4. 
              
  4. Звёзды уйдут платной реакцией. NFT появятся на витрине и оплатятся позже.
    5. 
            

            
Локальный пароль tdata вводится только на время запуска и не сохраняется. Токен бота остаётся в локальном файле настроек приложения.
